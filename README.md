# Xamcost Personal Website

This repository contains the source code for my personal website. It uses [Astro](https://astro.build) as the
static site generator.

## Development

For nix users, a nix flakes configuration is provided, so you can set up a shell with all the dependencies needed to run the project using:

```bash
nix develop
```

For non-nix users, you can simply install the dependencies with:

```bash
npm install
```

Then, you can start the development server with:

```bash
npm run dev
```
